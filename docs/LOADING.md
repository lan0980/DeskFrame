# 使用成品与排错

全部是图形界面操作：不装开发环境、不装运行时、不编译、不执行命令。

## 1. 启动宿主

从 Releases 下载 `DeskFrame-win-x64.exe`，放到任意文件夹，双击运行。绿色单文件，不用解压也不用安装。

启动后自动打开「小部件管理」窗口，系统托盘同时留一个入口（双击托盘图标可再次唤起管理窗口）。窗口标题旁显示的就是当前版本号。

- 自带渲染引擎，不依赖 .NET / Node / WebView2 / Python
- 单实例：再次双击只会把已运行的管理窗口调到前台
- 关掉小部件窗口不会退出宿主，退出要用托盘菜单里的「退出 DeskFrame」

首次运行可能看到两条正常提示：

> SmartScreen「Windows 已保护你的电脑」——二进制未签名所致，点「更多信息 → 仍要运行」。

> Portable exe 第一次启动会自解压到系统临时目录，之后复用同一份解压结果，所以冷启动比后面几次慢。

## 2. 小部件从哪来

**首次启动就装好了。** 安装包内含 8 个小部件——时钟、系统监控、便签、快速启动、剪贴板速览、天气、番茄钟、总线事件监视。第一次运行时它们会被自动放进你的小部件目录并开始显示，管理界面里带「随机附送」标记。

不想要哪个，直接在卡片上点「卸载」。卸载过的内置小部件**不会被下一次启动自动装回**；真想找回，点「恢复默认」。

要加自己的或者别人的小部件，两种方式：

**装成品包** — 拿到 `<id>.widget.zip`，在管理窗口点「安装小部件包」选中它。宿主校验清单、解压到数据目录、直接创建窗口。

**放文件夹** — 把含 `widget.json` 的文件夹放进 `%AppData%\DeskFrame\widgets\`，或点「从文件夹添加」选中它。目录被实时监听，**丢进去就加载，拿走就卸载，不需要重启**。

## 3. 日常调整

| 操作 | 位置 |
|---|---|
| 启用 / 停用 / 重新加载 / 卸载 | 每个小部件卡片上的按钮 |
| 改配置 | 卡片下方按 `configSchema` 自动生成的表单 |
| 挪位置 | 直接拖小部件窗口（前提是小部件声明了拖拽区域） |
| 不让它被挪走 | 卡片里勾「锁定位置」 |
| 不透明度 / 点击穿透 / 保持置顶 | 卡片里的滑杆与勾选 |
| 允许联网 / 开机自启 / 全屏时收起 | 顶部「全局开关」面板 |
| 全部还原 | 「恢复默认」（需要点两次确认） |

**全屏时收起**：检测到某个程序占满整个显示器时，临时收起全部小部件，退出后恢复；你自己关掉的那些不会被重新显示。非 Windows 平台无法做这个检测，开关下方会直接写明当前不生效。改动这里不需要重启宿主，立即生效。

**状态角标**：部分小部件（如番茄钟）会在自己的卡片上显示一个角标，那是它通过接口留下的实时状态。

**天气取不到数据**：联网默认关闭。小部件声明了联网需求，还要你在全局开关里勾选「允许小部件联网」才放行。

## 数据落在哪

| 内容 | 位置 |
|---|---|
| 主配置、各小部件状态、内置小部件的卸载记录 | `%AppData%\DeskFrame\settings.json` |
| 已安装小部件 | `%AppData%\DeskFrame\widgets\<id>\` |
| 日志 | `%AppData%\DeskFrame\logs\YYYY-MM-DD.log` |

管理窗口的「打开小部件目录」「查看日志」是按钮，不用手敲路径。小部件自己的 `localStorage` 在宿主数据目录下的会话分区里，与其他小部件互相隔离。

## 排错

| 现象 | 原因与处理 |
|---|---|
| 列表里没有出现 | 文件夹缺 `widget.json`，或 `id` 与文件夹名不一致，或 `protocol` 不是 1；看日志里 `registry` 那一行 |
| 标红「已隔离」 | 10 秒内没调 `ready()`，或 60 秒内失败超过 5 次；改好后点「重新加载」，隔离计数会清零 |
| 内置的小部件不见了 | 之前卸载过，属于预期行为；点「恢复默认」会全部发还 |
| 窗口一片空白 | `entry` 指向的文件不存在，或引用了目录外的资源（宿主拦目录外导航） |
| 拖不动 | 小部件没写 `-webkit-app-region: drag`，这是小部件自己的样式问题 |
| 按钮点不动、输入框打不了字 | 可交互元素漏了 `no-drag`，被拖拽区域吞掉了 |
| 联网请求全部失败 | 见上面「天气取不到数据」，两处开关都要开 |
| 提示 `permission denied` | 小部件调用了清单里没声明权限的接口 |
| 想彻底还原 | 点「恢复默认」，或关掉宿主后删除 `%AppData%\DeskFrame\` 整个文件夹 |

## 边界

所有写入只发生在 `%AppData%\DeskFrame\` 与 `HKCU\...\Run` 的开机自启开关，随时可撤销。宿主不碰系统文件、不 patch Explorer、不做 DLL 注入与全局 Hook、不提权、不遥测，不打包系统图标、系统字体或 macOS 素材。
