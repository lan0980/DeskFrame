# 下载成品后的加载流程

全程图形界面操作：**不安装开发环境、不装运行时、不编译、不调试、不执行任何命令行**。

## 1. 拿宿主

打开仓库的 **Releases** 页面，下载 `DeskFrame-win-x64.zip`，用资源管理器右键「全部提取」解压到任意文件夹（例如 `D:\DeskFrame\`）。双击里面的 `DeskFrame.exe`。

首次启动会自动打开「小部件管理」窗口，并在托盘留一个入口。**这是绿色版**：不写系统目录、不改注册表安装项、自带渲染引擎，不需要 .NET / Node / WebView2 / Python。

> 未签名的 exe 可能触发 Windows SmartScreen 提示「Windows 已保护你的电脑」。这是正常的，点「更多信息 → 仍要运行」即可；项目 README 与许可文件里已附免责声明。

## 2. 加载小部件（两种，任选）

**A. 成品包（推荐）**
从 Releases 下载 `<id>.widget.zip` → 在管理窗口点「安装 .widget.zip」→ 选中文件 → 完成。宿主会校验清单、解压到自己的数据目录、自动创建窗口。

**B. 文件夹**
把含 `widget.json` 的文件夹放进 `%AppData%\DeskFrame\widgets\`，或在管理窗口点「添加本地文件夹」选中它。宿主监听该目录，**丢进去就加载，拿走就卸载，不需要重启主程序**。

## 3. 调整

管理窗口里可以：启用 / 停用 / 重载 / 卸载；按 `configSchema` 自动生成的表单改配置；拖动窗口改位置（自动保存）；调不透明度、点击穿透、置顶；全局开关「允许联网」「开机自启」「全屏时隐藏」。

## 数据落在哪

| 内容 | 位置 |
|---|---|
| 主配置 | `%AppData%\DeskFrame\settings.json` |
| 已安装小部件 | `%AppData%\DeskFrame\widgets\<id>\` |
| 日志 | `%AppData%\DeskFrame\logs\YYYY-MM-DD.log` |

管理窗口的「打开小部件目录 / 打开日志 / 恢复默认」都是按钮，不用敲路径。

## 排错

| 现象 | 原因与处理 |
|---|---|
| 列表里没有小部件 | 文件夹里缺 `widget.json`，或 `id` 与文件夹名不一致；看日志 |
| 标红「已隔离」 | 60 秒内失败超过 5 次，或没调 `ready()`；改好后点「重载」 |
| 窗口一片空白 | `entry` 指向的文件不存在，或引用了目录外的资源 |
| 外链 / 网络请求失败 | `network` 权限默认关闭，需在全局设置里显式开启 |
| 想全部还原 | 点「恢复默认」，或删掉 `%AppData%\DeskFrame\` 整个文件夹 |

## 可逆性与边界

所有改动只落在上面这个用户数据目录和 `HKCU\...\Run` 的开机自启开关，随时可撤销。宿主不碰系统文件、不 patch Explorer、不做 DLL 注入与全局 Hook、不提权、不遥测；不打包任何系统图标、系统字体或 macOS 素材。
